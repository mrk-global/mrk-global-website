# MRK GLOBAL Website

Responsive one-page eCommerce marketplace service website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive design
- `script.js` — mobile navigation and demo form handling

## Before publishing
1. Replace every `https://wa.me/` link with your WhatsApp URL, for example:
   `https://wa.me/9715XXXXXXXX`
2. Update contact details and business email.
3. Connect the inquiry form to Formspree, Netlify Forms, your own PHP/API backend, or another form service.
4. Add your official MRK GLOBAL logo if available.
5. Add your domain after deploying.

## Hosting options
### Netlify
Drag the entire folder into Netlify Drop or connect the folder from GitHub.

### Cloudflare Pages
Upload the project through a Git repository. No build command is required.

### GitHub Pages
Upload the files to a repository and enable Pages from the repository settings.

## Local preview
Open `index.html` directly in your browser.
